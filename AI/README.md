## What's Inside

The folder contains two main types of learning material:

- **Python scripts (`.py`):** Small, focused exercises that you can run individually and modify as you learn.
- **Jupyter notebooks (`.ipynb`):** Interactive practical work that combines code cells with their outputs, making it easier to experiment with examples.

The exercises focus primarily on programming fundamentals and introductory logic. Although the directory is named `AI`, not every file implements an artificial intelligence algorithm.

<summary><strong>2. Conditions and Decision-Making</strong></summary>

These exercises demonstrate how a program can make decisions based on conditions.

| File | What it covers |

<details>
<summary><strong>3. Strings and Text Processing</strong></summary>

[`String_operation.py`](./String_operation.py) explores basic string manipulation, including:

- Finding the length of a string.
- Converting text to uppercase and lowercase.
- Replacing spaces with underscores.
- Checking whether the word `python` appears in the input.

**Try this:** Test a sentence containing `Python` with a capital `P`. Compare the result with a sentence containing lowercase `python`, then consider how to make the search case-insensitive.

</details>

## Jupyter Notebooks

The notebooks provide a more interactive way to explore the concepts in this folder.

### Practical notebook 1

**File:** [`pp1.ipynb`](./pp1.ipynb)

This notebook revisits introductory Python concepts, including output, data types, arithmetic, conditional statements, and string operations.

Use it to run examples cell by cell and compare the output with the equivalent standalone scripts.

### Practical notebook 2

**File:** [`pp2.ipynb`](./pp2.ipynb)

This notebook includes practical examples involving:

- `while` and `for` loops.
- Multiplication tables.
- Pattern printing.
- Lists, dictionaries, and sets.
- String slicing and reversal.

These exercises are useful for practising repetition, indexing, and working with collections.
